# Agent instructions

## Agent skills

### Issue tracker
Specs and tickets live in GitHub Issues in averyfreeman/ubuntu-fleet-manager; use gh. See docs/agents/issue-tracker.md.

Use the approved canonical labels needs-triage, needs-info, ready-for-agent, ready-for-human, and wontfix. See docs/agents/triage-labels.md.

### Domain docs
Single-context domain documentation uses root GLOSSARY.md and docs/adr/. See docs/agents/domain.md.
